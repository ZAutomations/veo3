Full Voiceover First is a separate opt-in narration workflow. Native Veo and fixed-clip Audio First remain available.

In Audio settings choose API narration and a voice (or provide a full local recording using the existing per-story local audio manifest). Choose English only or English plus selected languages and save each voice. In Agent Mode enable Full Voiceover First, select narrated saved stories, then Generate story batch. Both audio-first toggles are mutually exclusive. Reopen Studio after updating Python backend code.

The worker combines the source narration into one recording. For new Google English jobs, it asks for the scripted runtime at the native speaking pace and can request one faster delivery. The shared visual schedule follows the measured English timing. For six 10-second script blocks it targets 60 seconds and permits at most seven clips. Local word timestamps align existing visual beats. New packages live under each original story's `full_voiceover` folder. Source stories, recordings and old checkpoints are retained.

Finishing mixes the continuous narration at 1.00x. Speech gaps and the voice pace are preserved. Excess footage after the speech plus 0.30 seconds is removed; the appended thumbnail remains. Existing camera transitions, captions and SFX can still run. Final speed and narration silence trimming are bypassed only in this mode. Incorrectly short generated clips or uncertain transcript alignment stop the job before mixing or generation respectively.

For multilingual stories, the worker measures each selected language before Flow. It prepares shared visual clips and retimes the visual beats for each export while keeping the full narration at 1.00x. The mode supports narrated stories. A long story exceeding Google's 4000-byte full-request limit needs a shorter script or a full local recording. Word-level Whisper must be installed locally. There is no promise that Google speech, Whisper or Flow will produce a particular runtime or accurate content without review. Tests use synthetic media and mocked speech APIs; a real Flow generation trial is still required.

Prompts tab appends the shared audio-workflow choice to each story master prompt. Keep the existing import grammar and source word budgets; original Clip blocks represent authoring beats. The full-track mode determines the final visual clip count from the recorded voice, not from those source block numbers.
